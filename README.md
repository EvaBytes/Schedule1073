# Schedule1073

App Web para crear y gestionar horarios de empleados por secciones.

## Características
- Generación automática de horarios.
- Organización de empleados por secciones.
- Gestión de disponibilidad y ausencias.
- Edición manual de turnos.
- Almacenamiento de datos en el navegador.

## Tecnologías
- HTML
- CSS
- JavaScript
- Vite
